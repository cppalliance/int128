[#mixed_ops]
= Mixed Type Operations
:idprefix: mixed_ops

== Conversions

The ability to convert between the two types via `static_cast` is available as documented in the above class descriptions.

== Comparisons and Arithmetics

Mixed-sign comparisons and arithmetic between `int128_t`, `uint128_t`, and built-in integer types of opposite signedness follow the C++ usual arithmetic conversions.
The results are identical to those produced by the built-in `__int128` / `unsigned __int128` types: when the two operands have the same rank (e.g. `int128_t` and `uint128_t`), the signed operand is converted to its unsigned counterpart and the operation is performed unsigned.
When the library type has higher rank than the built-in opposite-signedness type and can represent it (e.g. `int128_t op uint64_t`), both operands are converted to the library type and the operation is signed.

In all cases the result value matches what the equivalent built-in `__int128` / `unsigned __int128` operation would produce, including two's-complement wrap-around behavior.

[source, c++]
----
namespace boost {
namespace int128 {

//=====================================
// Comparison Operators
//=====================================

BOOST_INT128_HOST_DEVICE constexpr bool operator==(uint128_t lhs, int128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr bool operator==(int128_t lhs, uint128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr bool operator!=(uint128_t lhs, int128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr bool operator!=(int128_t lhs, uint128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr bool operator<(uint128_t lhs, int128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr bool operator<(int128_t lhs, uint128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr bool operator<=(uint128_t lhs, int128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr bool operator<=(int128_t lhs, uint128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr bool operator>(uint128_t lhs, int128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr bool operator>(int128_t lhs, uint128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr bool operator>=(uint128_t lhs, int128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr bool operator>=(int128_t lhs, uint128_t rhs);

//=====================================
// Arithmetic Operators
//=====================================

BOOST_INT128_HOST_DEVICE constexpr uint128_t operator+(uint128_t lhs, int128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr uint128_t operator+(int128_t lhs, uint128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr uint128_t operator-(uint128_t lhs, int128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr uint128_t operator-(int128_t lhs, uint128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr uint128_t operator*(uint128_t lhs, int128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr uint128_t operator*(int128_t lhs, uint128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr uint128_t operator/(uint128_t lhs, int128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr uint128_t operator/(int128_t lhs, uint128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr uint128_t operator%(uint128_t lhs, int128_t rhs);

BOOST_INT128_HOST_DEVICE constexpr uint128_t operator%(int128_t lhs, uint128_t rhs);

} // namespace int128
} // namespace boost

----

The cross-type comparison operators return the same result as `static_cast<uint128_t>(lhs) op static_cast<uint128_t>(rhs)`.
The cross-type arithmetic operators return the same value as that expression and have return type `uint128_t`.
